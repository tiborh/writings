## Reading and maintenance

Files use language-code names and metadata with inclusive source-page
ranges. Original page text is kept in fixed-width blocks, preserving
extracted layout and any textual attribution/rights markings. This is not
a complete visual replica: images and pictograms are not reproduced.
Consult the original PDF for diagrams, dial symbols and safety-critical
details; extraction may contain errors.

Treat these as source editions, not experiment notes. Put new conclusions
in the microwave knowledge base and observations in the relevant learning
record. The complete extraction remains an archive; prefer individual
language files to avoid reading unrelated material.

Third-party source material is not covered by the repository's CC0
dedication. Attribution is retained; no new copyright notice is invented.
